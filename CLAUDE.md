# TG Triage — инструкции для Claude

Go-сервис: Telegram Business бот + веб-панель, LLM-триаж сообщений в задачи. Архитектура
`domain → service → repository/delivery`, см. README.

## Проверка перед коммитом

```bash
gofmt -l -w internal cmd
go vet ./...
go test ./...
```

`make test` использует `-race`, которому на Windows нужен CGO — локально гоняем без `-race`, в CI он есть.
Если vet или тесты падают — не коммитить, не пушить и не деплоить, сообщить пользователю.

## После больших правок: коммит, пуш, деплой

Большая правка — новая фича, рефакторинг, исправление в нескольких файлах. После неё, без отдельного
вопроса пользователю:

1. Проверка (см. выше).
2. Коммит в `main` и `git push origin main`.
3. Деплой на сервер — всегда, если менялся код бинарника (Go-код или `internal/delivery/webapp/static`,
   он вшит в бинарник). Правки только README/документации деплоя не требуют.
4. Убедиться, что сервис `active` и в логах нет ошибок старта; сообщить пользователю результат.

Доступ на сервер — по SSH-ключу, он уже настроен на этой машине. Хост, пути и точные команды деплоя —
в `CLAUDE.local.md` (не в git: репозиторий публичный).
